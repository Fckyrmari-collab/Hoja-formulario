# Sistema de Registro de Hojas de Vida

Proyecto React corregido.

## Para abrirlo

1. Abre esta carpeta en Visual Studio Code.
2. Abre una terminal en esta carpeta.
3. Ejecuta:

```bash
npm install
npm run dev
```

4. Abre la dirección que muestre Vite en el navegador.
